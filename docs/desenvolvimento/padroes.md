# Padrões de Desenvolvimento

---

## **1. Python**
- seguir PEP8
- nomes descritivos
- comentários apenas onde necessário

---

## **2. Django**
- usar Class-based Views quando possível
- separar lógica em services/helpers
- usar templates limpos e organizados

---

## **3. Estrutura**
- manter responsabilidades separadas
- reaproveitar componentes
- evitar duplicação de código
