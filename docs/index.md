# ADA – Chatbot SENAC

Bem-vindo à documentação oficial do **ADA**, um chatbot desenvolvido para auxiliar usuários com dúvidas sobre o programa **Jovem Programador – SENAC/SC**.

Esta documentação foi criada utilizando **MkDocs + Material for MkDocs** para fornecer uma visão clara sobre:

- a arquitetura do projeto  
- a lógica do chatbot  
- as tecnologias utilizadas  
- como instalar e rodar o projeto  
- detalhes técnicos (models, views, urls, templates)  
- API e fluxo de comunicação  

---

## Visão Geral

O ADA é um chatbot baseado em regras (rule-based) que oferece respostas estruturadas a partir de uma base de conhecimento fixa.  
Ele foi criado em **Python + Django** e pode ser integrado facilmente ao site institucional.

---

## Funcionalidades Principais

- Responder perguntas frequentes sobre o programa Jovem Programador  
- Interpretar mensagens do usuário utilizando lógica de mapeamento  
- Exibir respostas pré-definidas ou orientações  
- Registrar interações (opcional)  
- Facilmente extensível para novas intenções e respostas
