# Base de Conhecimento

A base de conhecimento é a fonte primária de respostas do chatbot.

---

## **1. Estrutura**
O chatbot consulta:
- perguntas frequentes (FAQ)
- categorias de dúvida
- respostas pré-formatadas

---

## **2. Funcionamento**
A base pode estar:
- embutida no código (listas/dicionários)
- carregada via arquivo externo
- atualizada por administradores (opcional)

---

## **3. Extensões Futuras**
- integração com API externa
- integração com banco de dados
- permitir que instrutores adicionem respostas dinamicamente.
