# Objetivos do Projeto

O projeto **ADA** foi desenvolvido com o propósito de criar um chatbot simples, eficiente e de fácil manutenção para responder dúvidas sobre o programa **Jovem Programador – SENAC/SC**.

---

## 🎯 Objetivos Técnicos

- Criar uma aplicação Django modular e organizada  
- Utilizar uma base de conhecimento estruturada  
- Desenvolver uma lógica limpa para identificar intenções  
- Permitir integração com uma interface web  
- Facilitar expansão futura com novas intenções e funcionalidades  

---

## 🎯 Objetivos Funcionais

- Fornecer respostas rápidas e claras para dúvidas comuns  
- Ajudar novos alunos a entender como funciona o programa  
- Reduzir a carga de atendimento humano  
- Garantir consistência nas respostas  
- Ser um recurso acessível e responsivo  

---

## 🎯 Objetivos Educacionais

- Servir como exemplo prático de desenvolvimento Django  
- Demonstrar implementação de um chatbot baseado em regras  
- Ajudar estudantes de programação a compreender:
  - rotas
  - views
  - templates
  - organização de projetos Django

---

## Escopo do Projeto

O ADA **utiliza IA** para responder às perguntas dos interessados com base no conteúdo do site.  
Ele foi projetado para:  

Isso garante simplicidade, acessibilidade e previsibilidade.
