# Requisitos do Sistema

Para executar o projeto ADA localmente ou em produção, é necessário garantir que o ambiente atenda aos requisitos mínimos listados abaixo.

---

## 🖥️ Sistema Operacional

O projeto pode ser executado nos seguintes sistemas:

- Windows 10 ou superior  
- Linux (Ubuntu 20.04+ recomendado)  
- macOS 12+  

---

## 🧰 Dependências principais

| Ferramenta          | Versão Recomendada |
|---------------------|--------------------|
| Python              | 3.10+             |
| Django              | 4.x               |
| Pip                 | Última versão     |
| Virtualenv          | Opcional, porém recomendado |
| MkDocs              | Para documentação |

---

## 🗄️ Banco de Dados

O projeto utiliza:

- **SQLite** (padrão do Django, já incluído no repositório)  
- Pode ser migrado para PostgreSQL ou MySQL se necessário  

---

## 🌐 Requisitos de Navegador

Para testar o frontend, recomenda-se:

- Google Chrome  
- Microsoft Edge  
- Firefox  

---

## 🔌 Outras Dependências

As bibliotecas Python utilizadas se encontram no arquivo:

requirements.txt


Elas serão instaladas automaticamente durante o processo de instalação do projeto.
