# Instalação do Projeto

Este guia descreve como configurar o ambiente, instalar dependências e preparar o projeto ADA para execução local.

---

## 1. 📥 Clone o repositório

No terminal, execute:

```bash
git clone https://github.com/renatoteodoro/ADA.git

Entre na pasta:

cd ADA

2. 🧪 Crie o ambiente virtual
python -m venv venv


Ative:

Windows

venv\Scripts\activate


Linux/macOS

source venv/bin/activate

3. 📦 Instale as dependências
pip install -r requirements.txt

4. 📚 Instale ferramentas auxiliares (opcional)
pip install mkdocs mkdocs-material

5. ✔️ Confirme se tudo está ok
python manage.py check


Se não houver erros, a instalação está concluída.
